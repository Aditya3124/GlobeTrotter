# 🌎 GlobeTrotter

GlobeTrotter is a modern, AI-powered travel planning and itinerary management application. It features a stunning minimalist UI inspired by neomorphism and neobrutalism, offering users a seamless experience for planning, viewing, and sharing their travel adventures.

## ✨ Features Implemented So Far

### 1. 🏠 Dashboard & Landing Page
- Modern hero section featuring a dynamic, transparent 3D globe illustration.
- Clean top navigation bar with integrated links to core features.
- "Previous Trips" showcase section at the bottom of the page.

### 2. 🔐 Authentication
- **Login & Signup:** Beautifully styled forms using a modern 2-column grid layout.
- Comprehensive user detail collection (Name, Phone, City, Country, Additional Info).

### 3. ✈️ Trip Management (My Trips)
- Centralized trip dashboard categorizing trips into **Ongoing, Upcoming, and Completed**.
- Full-width horizontal trip cards providing quick overviews, dates, and actions.
- Integrated search bar and filtering controls.

### 4. 📅 Trip Viewer & Itinerary Builder
- **List View:** Detailed timeline of stops, activities, and estimated costs.
- **Calendar View:** An interactive 7-day visual grid highlighting active trip days, stops, and activities.
- Seamless, instant toggling between List and Calendar views.

### 5. 🗺️ Interactive Maps
- Integrated `react-leaflet` with premium **CartoDB Voyager** tiles.
- Custom, modern `divIcon` markers to pinpoint destinations on a clean map interface.

### 6. 🔍 Explore / Search Page
- Dedicated search interface for finding activities, cities, and attractions.
- Comprehensive filtering controls (Group by, Filter, Sort by).
- Detailed horizontal result cards featuring pricing, locations, and descriptions.

### 7. 👥 Community Hub
- A social feed where travelers can share updates, itineraries, and tips.
- Includes a robust search and filtering system identical to the Explore page.

### 8. 👤 User Profile
- Detailed user header with profile image, stats (Trips, Countries), and contact information.
- Horizontally scrolling carousels displaying **Preplanned Trips** and **Previous Trips**.

## 🛠️ Tech Stack
- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** TypeScript
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Minimalist / Soft-shadow Neomorphism)
- **State Management:** [Zustand](https://github.com/pmndrs/zustand)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Maps:** Leaflet / React-Leaflet

## 🚀 Getting Started

1. Clone the repository
2. Navigate to the frontend directory: `cd frontend`
3. Install dependencies: `npm install`
4. Run the development server: `npm run dev`
5. Open [http://localhost:3000](http://localhost:3000) in your browser.
